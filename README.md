## If a graph/card shows zero / wrong year — quick fixes (do these, in order)

1. **Check username** — open the graph URL in browser to confirm:  
   `https://github-readme-activity-graph.vercel.app/graph?username=nubprogrammer`  
   If it 404s or errors, the username is wrong or the service is down.

2. **Confirm commits meet GitHub's rules** — contributions count only when:
   - The commit email is associated with your GitHub account.
   - The commit is in the repo’s default branch (or gh-pages).
   - It’s not a fork (unless merged into original).
   - The repo is public OR you enabled private contributions on your profile.

3. **Fix your local git email (if needed)**  
   Run:
   ```bash
   git config user.name "Your Name"
   git config user.email "your-email@example.com"
   # For global:
   git config --global user.email "your-email@example.com"
